TAKINTA EDITABLE SITE, ACCOUNTS & INQUIRY CART

Install this plugin ZIP from WordPress Admin > Plugins > Add New > Upload Plugin. Keep the Takinta Static Site theme active and activate the plugin.

Open Tools > Takinta Content Import to import all bundled HTML pages. The plugin serves editable database copies on the existing .html routes, falling back to the theme's original static files until import is complete. Account links in the site header lead to the new account portal.

Account pages: /account/ and /register/; Persian: /fa/account/ and /fa/register/. Members can sign in, register as Subscriber, edit profile names, reset passwords, and sign out. The product enquiry cart is at /cart/ and /fa/cart/: it collects products and quantities and emails a quote request. It does not calculate prices, create orders, or take payment.

A detailed Persian guide is included as EDITABLE-FA.md. Configure the site's privacy policy and test WordPress email/SMTP delivery before public launch.
