TAKINTA EDITABLE SITE CONTENT

Install this plugin ZIP from WordPress Admin > Plugins > Add New > Upload Plugin. Keep the Takinta Static Site theme active, activate this plugin, then open Tools > Takinta Content Import and start the import.

Imported pages are stored in the WordPress database as editable HTML source and served on their existing .html routes. Product pages are editable content, not WooCommerce products. No cart, checkout, stock, or payment integration is created.

A detailed Persian guide is included as EDITABLE-FA.md.
