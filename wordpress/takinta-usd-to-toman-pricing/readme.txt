تبدیل خودکار قیمت دلار به تومان برای WooCommerce

نسخه: 1.0.0
نیازمندی‌ها: WordPress 6.0+، PHP 7.4+ و WooCommerce

این افزونه قیمت پایهٔ دلاری هر محصول را با نرخ دلار آزاد از API رایگان Iran Market Data تبدیل می‌کند و قیمت عادی (Regular price) ووکامرس را به‌روزرسانی می‌کند. نرخ از نماد USD_IRR_FREE در فایل عمومی popular.json خوانده می‌شود؛ واحد نرخ API تومان است و افزونه آن را به ریال تبدیل نمی‌کند، مگر اینکه در تنظیمات واحد «ریال» را انتخاب کنید.

نصب و شروع

1. پوشهٔ takinta-usd-to-toman-pricing را در wp-content/plugins قرار دهید یا ZIP را از پیشخوان WordPress > افزونه‌ها > افزودن > بارگذاری افزونه نصب کنید.
2. افزونه را فعال کنید. WooCommerce > قیمت دلار به تومان را باز کنید.
3. واحد قیمت فروشگاه را انتخاب کنید. مقدار پیش‌فرض تومان است؛ اگر مقادیر قیمت عادی ووکامرس را به ریال ذخیره می‌کنید، «ریال (تومان × ۱۰)» را برگزینید.
4. هر محصول را ویرایش کنید. در اطلاعات محصول > همگانی، مبلغ پایهٔ آن محصول را به USD وارد و «به‌روزرسانی خودکار از نرخ دلار» را فعال کنید. برای محصولات متغیر، این تنظیم را برای تک‌تک متغیرها وارد کنید.
5. «دریافت نرخ و همگام‌سازی» را بزنید. پس از آن، نرخ و قیمت محصولات واجد شرایط به‌طور خودکار هر ۳۰ دقیقه بررسی می‌شوند.

قیمت دستی و دامنهٔ تغییرات

- فقط محصولاتی به‌روزرسانی می‌شوند که هم قیمت USD معتبر داشته باشند و هم گزینهٔ به‌روزرسانی خودکارشان روشن باشد.
- برای تغییر دستی، گزینهٔ به‌روزرسانی خودکار را خاموش کنید، قیمت دلاری خودکار را خالی یا نگه دارید و مبلغ را در فیلد معمول قیمت عادی WooCommerce وارد کنید. افزونه در حالت خاموش قیمت را بازنویسی نمی‌کند.
- قیمت حراج (Sale price) جداگانه و دستی باقی می‌ماند. افزونه فقط قیمت عادی را تبدیل می‌کند.
- محصولات متغیر بر اساس قیمت هر متغیر پردازش می‌شوند. محصول گروهی پشتیبانی نمی‌شود.
- افزونه قیمت USD را حدس نمی‌زند و کالای بدون مبلغ پایهٔ دلاری را تغییر نمی‌دهد. در کاتالوگ فعلی Takinta، قیمت دلاری مبنا به‌صورت دادهٔ محصول ثبت نشده؛ مبلغ پایه را باید برای محصول‌های موردنظر وارد کنید.
- اگر API خطا بدهد یا داده را کهنه اعلام کند، همگام‌سازی متوقف می‌شود و آخرین قیمت‌های ووکامرس حفظ می‌شوند.

زمان‌بندی

همگام‌سازی خودکار از WP-Cron استفاده می‌کند؛ WP-Cron معمولاً با بازدید سایت اجرا می‌شود. برای فروشگاه کم‌بازدید یا نیاز به زمان‌بندی دقیق، Cron سرور را برای اجرای wp-cron.php تنظیم کنید. اجرای دستی از صفحهٔ افزونه نیز همیشه در دسترس است.

منبع نرخ: https://iran-market.github.io/ — فایل دادهٔ عمومی popular.json، نماد USD_IRR_FREE. نرخ، رایگان و بدون کلید API دریافت می‌شود.
