A shelving system for many sectors

With the Slimline shop shelf, you have a shop fitting system with many advantages. The deliberately unobtrusive design allows it to be used for many retail sectors. Whether homeware, fashion or decoration, with the Slimline shelving system you are guaranteed to have an extraordinary interior.

Flexible set up for beauty and hair salons

The Slimline shelving system is the ideal solution for a filigree design in shop fitting for cosmetics and spa areas. With Slimline, you can set up your studio or spa area quickly and easily, and display products such as cosmetics beautifully.
